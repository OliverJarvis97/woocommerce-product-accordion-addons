# WooCommerce Product Accordion Add-ons

Optional WooCommerce product add-ons displayed as compact accordions on product pages. Selected add-ons are added only when the main product is added to cart and always use quantity one.

## Releases and updates

Push a tag such as `v1.6.1` to create a GitHub Release with an installable ZIP. The installed plugin checks the latest GitHub Release and exposes newer releases in the normal WordPress Plugins dashboard. Enable WordPress auto-updates for the plugin if you want future releases installed automatically.
